# Documentation index

Start with the repository `README.md`, then:

| File | What it is |
|---|---|
| `goals.md` | the project direction (two tracks), milestones and stop conditions |
| `gaps.md` | every study's claims and falsifiers, written before the code (G1 to G19) |
| `preregistration-g20.md` | the G20 model and six predictions, committed before the run |
| `results.md` | index of the results record, split by study under `results/`; `results/summary.md` has the conclusions C1 to C17 and the collected list of failures and rejected ideas |
| `assumptions.md` | every parameter in `config/params.toml` with its tier; generated, do not edit |
| `fpga-board.md` | how to build and use the DE2-115 design (compiled in Quartus, not yet run on a board) |
| `audit-2026-11.md` | the November 2026 audit: structure, use case, credibility, reproducibility, ranked by severity |
| `path-forward.md` | honest assessment of money, funding routes, how to approach professors, a plan to 30 November 2026 |
| `planning/` | material about direction rather than evidence: two role-played council reviews, the collaboration offer for 2D-materials groups, and the (superseded) pitch deck |

Rules the documents follow: every number comes from a script in this repository; nothing is a measurement;
failures and wrong predictions are kept; no novelty is claimed; no claim is made that any 2D circuit is
radiation resistant.
