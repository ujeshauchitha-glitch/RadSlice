# G19 step 1: the quantized digit classifier (fault-free)

Network 64-32-10 on scikit-learn's bundled 8x8 digits, 1257 training and 540 held-out images
(seed 1). int8 weights, int32 accumulators, hidden activations clipped to 0..127 after a shift of 9 bits.

| | held-out accuracy |
|---|---|
| float network | 0.9704 |
| integer network (the reference for the array) | 0.9685 |

The integer network agrees with the float network's prediction on 0.9981 of the held-out images.
Multiply-accumulates per image: 2368. Weights: 2368 bytes plus 42 biases.
